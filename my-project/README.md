## 🚀 Getting Started

### Step 1️⃣: Clone or Extract Project

```bash
# Navigate to project directory
cd my-project
```

### Step 2️⃣: Install Dependencies

```bash
# Install all npm packages
npm install

# This creates node_modules folder and installs all dependencies
# Takes 2-5 minutes depending on internet speed
```

### Step 3️⃣: Start Development Server

```bash
# Start Vite dev server with Hot Module Replacement
npm run dev

# Output:
# ➜  Local:   http://localhost:5173/
# ➜  Press q to quit
```

### Step 4️⃣: Open in Browser

```
http://localhost:5173
```

You should see the Cross Stitch homepage with full functionality!

### Development Workflow

```bash
# Make changes and see them instantly (HMR)
# 1. Edit component files in src/
# 2. Save file (Ctrl+S)
# 3. Browser auto-refreshes

# Check code quality
npm run lint

# Fix linting issues automatically
npm run lint -- --fix

# Build for production
npm run build

# Preview production build
npm run preview
```

### Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Port 5173 already in use | `npm run dev -- --port 3000` |
| Module not found | `rm -rf node_modules` then `npm install` |
| Cache issues | Clear browser cache (Ctrl+Shift+Delete) |
| Linting errors | Run `npm run lint -- --fix` |
| Images not loading | Check path in imports vs public folder |

## 🗄️ State Management

### CartContext

**Location**: `src/context/CartContext.jsx`

**State Structure**:
```javascript
{
  cart: [
    {
      id: string,
      name: string,
      image: string,
      price: number,
      size: string,
      quantity: number
    }
  ]
}
```

**Available Functions**:

```javascript
// Add product to cart
addToCart(product, size, quantity)

// Remove item from cart
removeFromCart(productId, size)

// Update item quantity
updateQuantity(productId, size, newQuantity)

// Clear entire cart
clearCart()

// Get total number of items
getTotalItems()

// Get total price in PKR
getTotalPrice()
```

**Persistence**:
- Automatically saved to localStorage on every change
- Restored from localStorage on app startup
- Survives browser refresh and restart

## 🤝 Contributing

### Development Guidelines

1. **Code Standards**
   - Use functional components with hooks
   - One component per file
   - Meaningful variable names
   - Comments for complex logic

2. **Naming Conventions**
   - Components: PascalCase (ProductCard.jsx)
   - Functions: camelCase (calculateTotal)
   - Classes: kebab-case (.product-card)

3. **Before Committing**
   ```bash
   npm run lint -- --fix
   npm run build
   ```

4. **Testing Checklist**
   - [ ] Test on mobile (480px)
   - [ ] Test on tablet (768px)
   - [ ] Test on desktop (1024px+)
   - [ ] Check console for errors
   - [ ] Test cart functionality
   - [ ] Test checkout flow

### Pull Request Process

1. Create feature branch: `git checkout -b feature/description`
2. Make changes and test thoroughly
3. Run linter: `npm run lint -- --fix`
4. Commit with clear messages
5. Submit PR with detailed description
